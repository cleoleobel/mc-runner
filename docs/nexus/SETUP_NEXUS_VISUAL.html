PASO 01 DE 08 GitHub PAT Token

Generar Token Restringido en GitHub

Crea un Fine-grained Personal Access Token con principio de mínimo privilegio asignado únicamente a cleoleobel/nexus-storage.

Profile Picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens
Así se ve el botón en GitHub
[ + Generate new token ]
🛑 NO CONTINÚES HASTA VER

El token generado empezando por github_pat_... copiado en tu portapapeles.

PASO 02 DE 08 Playit Agent

Crear Agente de Red en Playit.gg

Crea el agente dedicado en Playit.gg para obtener la clave secreta de conexión.

playit.gg → Log In → Agents
Así se ve el botón en Playit.gg
[ Create Agent ]
🛑 NO CONTINÚES HASTA VER

La clave Secret Key de Playit.gg copiada.

PASO 03 DE 08 Playit Tunnels

Configurar Túneles en Playit.gg

Crea los dos túneles con los presets oficiales de Playit para Minecraft Java y Simple Voice Chat.

Playit Dashboard → Tunnels → Add Tunnel

PASO 04 DE 08 GitHub Repository Secrets

Guardar Secretos en el Repositorio

Registra las credenciales en los secretos del repositorio de GitHub.

cleoleobel/mc-runner → Settings → Secrets and variables → Actions
Así se ve el botón en GitHub
[ New repository secret ]
NOMBRE EXACTO EN GITHUB VALOR QUE DEBES PEGAR
NEXUS_STORAGE_TOKEN
 Pegar token github_pat_... generado en Paso 1
PLAYIT_SECRET
 Pegar clave Secret Key copiada en Paso 2
🛑 NO CONTINÚES HASTA VER

Ambos secretos listados bajo la sección Repository secrets.

PASO 05 DE 08 Validation Execution

Ejecutar Workflow de Validación Inicial

Ejecuta la operación atómica de verificación técnica en GitHub Actions.

cleoleobel/mc-runner → Actions → NEXUS Java Server → Run workflow
Así se ve el botón en GitHub Actions
[ ▶ Run workflow ]
🛑 NO CONTINÚES HASTA VER

Una ejecución iniciada en la lista con icono amarillo de progreso 🟡.

PASO 07 DE 08 Production Server

Iniciar Servidor en Producción

Inicia la sesión activa de juego en modo dedicado.

Actions → NEXUS Java Server → Run workflow
🛑 NO CONTINÚES HASTA VER

PASO 08 DE 08 Minecraft & Voice Chat

Conexión al Juego y Chat de Voz

Conéctate al servidor desde Minecraft Java 1.20.1 y confirma Simple Voice Chat.

Playit Dashboard (Copiar Host TCP) → Minecraft → Multiplayer → Add Server
🛑 NO CONTINÚES HASTA VER

Tu personaje en el juego y el menú de Simple Voice Chat abierto mostrando el micrófono activo (vinculado automáticamente por el runner).
