NEXUS — Guía Visual de Puesta en Marcha Definitiva

⏱️ Tiempo estimado: 10 - 15 minutos 📦 Repo: cleoleobel/mc-runner 💾 Storage: cleoleobel/nexus-storage

📋 Lo que vas a configurar

  • GitHub Fine-grained PAT Token: Permiso de lectura/escritura restringido exclusivamente a cleoleobel/nexus-storage.
  • GitHub Secrets: Claves de acceso privadas seguras en el repositorio cleoleobel/mc-runner.
  • Playit.gg Agent & Tunnels: Enrutamiento de red pública con presets oficiales (Minecraft Java TCP 25565 y MC: Simple Voice Chat UDP 24454).
  • GitHub Actions: Despliegue automatizado del servidor NEXUS.

🛡️ Lo que NO tendrás que hacer

  • ❌ No tendrás que programar ni editar código.
  • ❌ No tendrás que modificar archivos YAML ni scripts.
  • ❌ No tendrás que mover mods ni alterar server.properties.
  • ❌ No tendrás que editar manualmente voicechat-server.properties (el runner configura voice_host y bind_address=0.0.0.0 automáticamente).
  • ❌ No tendrás que ejecutar comandos de consola ni instalar Forge manualmente.
  • ❌ No tendrás que comprimir ni gestionar backups del mundo a mano.

PASO 1 — Generar Token de Acceso Personal Restringido (Fine-grained PAT) en GitHub

OBJETIVO: Crear un Token de acceso con principio de mínimo privilegio restringido a cleoleobel/nexus-storage.

DÓNDE ESTÁS: GitHub.com

RUTA: Profile Picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens

BOTÓN EXACTO: Generate new token

CONFIGURACIÓN:

  • Token name: NEXUS Storage Token
  • Expiration: 90 days
  • Resource owner: cleoleobel
  • Repository access: Seleccionar Only select repositories → cleoleobel/nexus-storage
  • Permissions: Repository permissions → Contents: Read and write

QUÉ HACER DESPUÉS: Haz clic al fondo en Generate token.

  └─ Settings → Developer settings → Personal access tokens → Fine-grained tokens
       └─ [Generate new token]
🛑 NO CONTINÚES HASTA VER: El token generado github_pat_... copiado en tu portapapeles.
PASO 2 — Crear Agente de Red en Playit.gg

OBJETIVO: Crear el agente dedicado de Playit.gg y obtener la clave secreta de conexión.

DÓNDE ESTÁS: Playit.gg Dashboard

RUTA: https://playit.gg → Log In → Agents

BOTÓN EXACTO: Create Agent

AGENT NAME: NEXUS-Runner

QUÉ HACER DESPUÉS: Haz clic en Create Agent y luego ubica Secret Key y haz clic en Copy.

🛑 NO CONTINÚES HASTA VER: La clave Secret Key de Playit.gg copiada.
PASO 3 — Configurar Túneles en Playit.gg (Minecraft & Simple Voice Chat)

OBJETIVO: Crear los túneles con los presets oficiales de Playit para Minecraft Java (TCP 25565) y Simple Voice Chat (UDP 24454).

RUTA: Playit.gg → Tunnels → Add Tunnel

  • Túnel 1 (Minecraft): Preset: Minecraft Java | Local IP: 127.0.0.1 | Local Port: 25565 → Add Tunnel
  • Túnel 2 (Voice Chat): Preset: MC: Simple Voice Chat | Local IP: 127.0.0.1 | Local Port: 24454 → Add Tunnel
🛑 NO CONTINÚES HASTA VER: Ambos túneles creados hacia 127.0.0.1.
PASO 4 — Guardar Secretos en GitHub

DÓNDE ESTÁS: cleoleobel/mc-runner → Settings → Secrets and variables → Actions

BOTÓN EXACTO: New repository secret

  • NEXUS_STORAGE_TOKEN = Tu Token (github_pat_...) → Add secret
  • PLAYIT_SECRET = Tu Secret Key de Playit → Add secret
🛑 NO CONTINÚES HASTA VER: Ambos secretos listados bajo Repository secrets.

RUTA: cleoleobel/mc-runner → Actions → NEXUS Java Server → Run workflow

PASO 7 & 8 — Producción & Conexión al Servidor

ARRANQUE: Actions → NEXUS Java Server → Run workflow → Operación: run-server.

CONEXIÓN EN MINECRAFT:

  • Multiplayer → Add Server
  • Server Address: <DIRECCION_PLAYIT>:<PUERTO>
  • Presiona V dentro del juego para validar Simple Voice Chat (vinculado automáticamente por el runner).
