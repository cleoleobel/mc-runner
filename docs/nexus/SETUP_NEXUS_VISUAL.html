NEXUS — Guía Visual de Puesta en Marcha Definitiva

⏱️ Tiempo estimado: 10 - 15 minutos 📦 Repo: cleoleobel/mc-runner 💾 Storage: cleoleobel/nexus-storage

📋 Lo que vas a configurar

  • GitHub PAT Token: Permiso de lectura/escritura para el almacenamiento del mundo.
  • GitHub Secrets: Claves de acceso privadas seguras en el repositorio.
  • Playit.gg Agent & Tunnels: Enrutamiento de red pública (TCP 25565 y UDP 24454).
  • GitHub Actions: Despliegue automatizado del servidor NEXUS.

🛡️ Lo que NO tendrás que hacer

  • ❌ No tendrás que programar ni editar código.
  • ❌ No tendrás que modificar archivos YAML ni scripts.
  • ❌ No tendrás que mover mods ni alterar server.properties.
  • ❌ No tendrás que ejecutar comandos de consola ni instalar Forge manualmente.
  • ❌ No tendrás que comprimir ni gestionar backups a mano.

PASO 1 — Generar Token de Acceso Personal (PAT) en GitHub

OBJETIVO: Crear un Token de acceso seguro para que el servidor guarde y descargue el mundo.

DÓNDE ESTÁS: GitHub.com

RUTA: Profile Picture → Settings → Developer settings → Personal access tokens → Tokens (classic)

BOTÓN EXACTO: Generate new token → Generate new token (classic)

CONFIGURACIÓN:

  • Note: NEXUS Storage Token
  • Expiration: No expiration
  • Select scopes: Marca la casilla repo

QUÉ HACER DESPUÉS: Haz clic al fondo en Generate token.

🛑 NO CONTINÚES HASTA VER: El token generado ghp_... copiado en tu portapapeles.
PASO 2 — Crear Agente de Red en Playit.gg

OBJETIVO: Obtener la clave secreta del agente Playit para abrir los puertos del servidor.

DÓNDE ESTÁS: Playit.gg Dashboard

RUTA: https://playit.gg → Log In → Agents

BOTÓN EXACTO: Add Agent

AGENT NAME: NEXUS-Runner

QUÉ HACER DESPUÉS: Haz clic en Create Agent y luego copia el Secret Key.

🛑 NO CONTINÚES HASTA VER: El Secret Key de Playit.gg copiado.
PASO 3 — Configurar Túneles en Playit.gg (TCP & UDP)

OBJETIVO: Crear los túneles para Minecraft (TCP 25565) y Voice Chat (UDP 24454).

RUTA: Playit.gg → Tunnels → Add Tunnel

  • Túnel 1 (Minecraft): Type: Minecraft Java | Protocol: TCP | Local Port: 25565 → Add Tunnel
  • Túnel 2 (Voice Chat): Type: Custom | Protocol: UDP | Local Port: 24454 → Add Tunnel
🛑 NO CONTINÚES HASTA VER: Ambos túneles creados hacia 127.0.0.1.
PASO 4 — Guardar Secretos en GitHub

DÓNDE ESTÁS: cleoleobel/mc-runner → Settings → Secrets and variables → Actions

BOTÓN EXACTO: New repository secret

  • NEXUS_STORAGE_TOKEN = Tu PAT token (ghp_...) → Add secret
  • PLAYIT_SECRET = Tu Secret Key de Playit → Add secret
🛑 NO CONTINÚES HASTA VER: Ambos secretos listados bajo Repository secrets.

RUTA: cleoleobel/mc-runner → Actions → NEXUS Java Server → Run workflow

ARRANQUE: Actions → NEXUS Java Server → Run workflow → Operación: run-server.

  • Server Address: <DIRECCION_PLAYIT>:<PUERTO>
